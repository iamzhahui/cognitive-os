## 一、Evolution OS — 世界演化推演系统

目标不是总结新闻，而是理解世界如何演化：技术→产业→组织→社会→权力→人性→新秩序的跨层级因果推演。

11步分析流程：
1. 事件本质（Essence Layer）：改变了什么能力/成本结构
2. 技术演化（Technology Layer）：萌芽/爆发/泡沫/基础设施化
3. 产业演化（Industry Layer）：价值链重构
4. 组织演化（Organization Layer）：岗位/管理/决策权变化
5. 社会结构演化（Society Layer）：教育/职业/贫富/价值观
6. 权力演化（Power Layer）：资源/规则/分发/平台控制
7. 人性演化（Human Nature Layer）：自由/依赖/情绪/稀缺能力
8. 新秩序推演（New Order Layer）：5-10年后的默认规则
9. 反向推演（Critical Layer）：主流观点可能错在哪
10. 认知资产调用（Knowledge Mapping）：哪本书/模型/案例最匹配
11. 输出要求：不直接下结论，输出8项（真正重要的/演化链/多数人没看到的/风险/机会/先适应者/观察信号/转折点标志）

## 二、Thinking OS — 7层思维系统

1. 哲学思维（定义问题）：现象vs原因vs结果，被隐藏的前提，重新定义问题
2. 系统思维（识别结构）：角色/资源/流程/规则，反馈回路，杠杆点
3. 概率思维（处理不确定性）：事实vs假设，置信度，黑天鹅
4. 经济思维（评估资源与代价）：显性/隐性成本，机会成本，ROI
5. 政治思维（看清人和权力）：利益相关方，权力结构，叙事策略
6. 军事思维（形成行动路径）：单目标，关键战场，第一场小胜利，最小验证动作
7. 元认知（校准自己）：情绪在保护什么，追求真相还是证明自己对了，5年后回看后悔什么

每层输出格式：关键提问 → 我可能忽略的盲点 → 下一步验证

## 三、CognitionFlow — 表达训练闭环

命名来源：ChatGPT建议，用户认可。不是"英语学习"，而是"认知流动系统"。

链路：输入 → 理解 → 结构化 → 表达 → 语言输出 → 应用 → 资产化

### 四层训练体系

第一层：结构输入（拆书）
- 不是"这本书讲了什么"，而是"这本书如何组织观点、为什么让我觉得清晰、作者怎么推进逻辑"
- 第一批书单：《金字塔原理》《学会提问》《麦肯锡教我的写作武器》《逻辑思考力》
- 第二批：《TED Talks》《非暴力沟通》《高难度谈话》

第二层：表达重构（核心）
- 把今天发生的事重新结构化表达（不是"总结今日内容"）
- 示例：AI Coding问题 → 金字塔表达（结论→原因→结果→改进方案）

第三层：口语压缩训练
- 把结构压缩成30秒/1分钟/3分钟版本
- 这是面试、汇报、方案售前、管理层沟通最核心的能力

第四层：英语映射（最后一步）
- 不是背单词学语法，是用"固定表达骨架"映射英语
- 中文骨架→英语固定化（I think the core issue is... / There are three reasons...）

### Daily Expression OS（日表达系统）
- Step1 输入（15min）：看表达类书/一个TED/一个优秀表达案例
- Step2 重构（20min）：把今天一个事重新结构化表达
- Step3 压缩（10min）：压成30秒/1分钟/3分钟
- Step4 英语映射（10min）：把1分钟版本转英语
- Step5 口语输出（10min）：直接说，追求连续表达不停顿有结构

### 拆书Skill结构
1. 核心命题（这本书解决什么问题）
2. 作者底层假设
3. 核心结构
4. 表达模式库（最重要）：结论→原因→行动 / 问题→原因→风险→方案 / 现状→矛盾→变化→结果
5. 可迁移场景：面试/AI方案汇报/工作日报/产品PRD/管理沟通/英语口语
6. 今日应用：今天工作中的一个问题的重新结构化表达

## 四、知识资产化 — 系统化学习与记忆

### 核心诊断
用户痛点："学完就忘，从小到大都这样，阶段性学习，学完就忘"
诊断：不是记忆力差，是知识没有进入长期认知系统。
- 普通人：学→用→忘（完成任务式学习）
- 高手：学→提炼→建模→应用→沉淀（构建认知资产）

### 关键转变
从"收集知识"到"收集模型"：
- 知识会忘，模型不会
- "反馈回路"比《系统之美》90%的内容更持久
- "结论先行"比《金字塔原理》很多内容更持久
- 模型比知识密度高

### 学习闭环
看书 → 找冲突 → 抽模型 → 找案例 → 进入知识库
（不是：看书→记笔记→收藏→结束）

### 四层提问框架
1. 这件事在解决什么问题？
2. 为什么以前做不好？
3. 底层规律是什么？
4. 能否迁移？

### 认知资产库结构
1. 模型库（最重要）：反馈回路、飞轮效应、委托代理、二阶效应、路径依赖、机会成本...
2. 案例库：真实案例（问题→方案→结果→教训）
3. 表达库：每天输出"今天学到了什么"200字
4. 英语库：当天输出翻译英文，练口语

### 核心行动建议
"从今天开始，不再问'这本书讲了什么'，而改问'这本书留下了哪3个我以后会反复使用的模型'。当你积累到100个左右高频模型时，你会发现自己不再依赖记忆细节，而是开始依赖认知框架思考。"

### MCP示例（模型化记忆）
不要记"MCP是什么"，记：
- 名称：MCP
- 本质：AI世界的USB协议
- 解决问题：工具接入标准化
- 适用场景：Agent
- 现实案例：Claude Code、Hermes Agent
- 一句话：MCP = AI调用工具的统一接口
