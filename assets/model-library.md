# 模型库（Model Library）

> 模型比知识密度高。知识会忘，模型不会。

> 验收：看到决策情境能自动跳过表象直接到结构分析。

## 模型列表

### 系统之美（6个）— Thinking OS L2 系统思维

| # | 模型 | 一句话定义 |
|---|------|-----------|
| 1 | 反馈回路 | 系统输出的一部分回流为输入，形成自强化或自调节循环 |
| 2 | 延迟 | 因果之间的时间差，扭曲因果判断 |
| 3 | 杠杆点 | 系统中改变一点就能引起系统性变化的关键节点 |
| 4 | 涌现 | 整体表现出部分不具备的行为特性 |
| 5 | 存量与流量 | 系统状态的积累量 vs 流入流出的速率 |
| 6 | 系统的真实目标 | 系统实际追求的目标（由行为推断），非声称目标 |

### 金字塔原理（7个）— Thinking OS L6 行动/表达

| # | 模型 | 一句话定义 |
|---|------|-----------|
| 7 | 结论先行金字塔 | 先给结论再展开论据，自上而下构建表达结构 |
| 8 | SCQA序言结构 | 情境→冲突→疑问→回答，制造认知张力引导阅读 |
| 9 | MECE分类原则 | 相互独立、完全穷尽，确保论据不重叠不遗漏 |
| 10 | 纵向疑问-回答对话 | 上一层的陈述引发下一层的疑问，逐层回答 |
| 11 | 横向归纳与演绎 | 同层论据要么归纳推理要么演绎推理，不能混用 |
| 12 | 自下而上提炼总结 | 从散点信息向上提炼出核心结论 |
| 13 | 三大顺序法则 | 按时间/结构/重要性排列论据 |

### 思考，快与慢（12个）— Thinking OS L7 元认知

| # | 模型 | 一句话定义 |
|---|------|-----------|
| 14 | Anchoring Bias 锚定效应 | 初始信息扭曲后续判断 |
| 15 | Availability Heuristic 可得性启发式 | 越容易想起的越被判断为高频/重要 |
| 16 | Representativeness Heuristic 代表性启发式 | 用相似性判断概率，忽略基数 |
| 17 | WYSIATI 闭合偏好 | 只用可得信息构建叙事，忽略未知 |
| 18 | Attribute Substitution 属性替代 | 用简单问题替代复杂问题（Fe劫持Te的机制） |
| 19 | Loss Aversion 损失厌恶 | 损失痛感是同等收益快感的2倍 |
| 20 | Framing Effect 框架效应 | 同一信息不同表述导致不同决策 |
| 21 | Hindsight Bias 后见之明 | 事后觉得"早该知道"，高估自己事前判断力 |
| 22 | Peak-End Rule 峰值-结尾规则 | 记忆由峰值和结尾决定，非平均体验 |
| 23 | Confirmation Bias 确认偏误 | 只搜索/接受支持自己预判的证据 |
| 24 | Halo Effect 晕轮效应 | 一个好/坏特征泛化到整体评价 |
| 25 | Overconfidence 过度自信 | 自信增长不等于精度增长 |
