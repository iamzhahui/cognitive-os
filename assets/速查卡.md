# Cognitive OS 速查卡

## 问题类型 → 模块映射

| 输入类型 | 优先模块 | 辅助模块 |
|----------|----------|----------|
| 现实问题/决策 | Thinking OS（含奇正层） | Models, Case Lab, Evolution OS |
| 双约束死结/找不到好选项 | Thinking OS→奇正层 | Models, Case Lab |
| 行业动态/趋势 | Evolution OS | Thinking OS, Models |
| 书籍/文章/理论 | Book Extraction | Models, Thinking OS, CognitionFlow |
| 真实案例/复盘 | Case Lab | Thinking OS, Models |
| 表达训练/日常输出 | CognitionFlow | Book Extraction, Models |
| 模型沉淀/场景 | Models Engine | Book Extraction, Case Lab |

## 模块分析步数

| 模块 | 步数 | 核心输出 |
|------|------|----------|
| Evolution OS | 11步 | 演化链 + 反向推演 + 信号清单 |
| Thinking OS | 7层+奇正层 | 问题重定义 + 盲点 + 验证动作；走不通时切奇正五步破局 |
| Book Extraction | 9步 | 认知冲突 + 模型 + Trigger + 压缩 |
| CognitionFlow | 4层 | 结构输入→表达重构→口语压缩→英语映射 |
| Case Lab | 5步 | 7层复盘 + Trigger + 反模式 + 原则 |
| Models Engine | 6步 | 模型抽象 + 联动 + Trigger + 压缩 |
| 知识资产存储 | 4库 | 模型库 + 案例库 + 表达库 + 英语库 |

## 核心原则（7条）

1. 不要一上来给结论
2. 不要替用户做最终决定
3. 先判断问题类型，再选择分析路径
4. 每层先提关键问题，再指出盲点
5. 信息不足时明确标注"需要验证"
6. 输出以"引导思考"为主
7. 最终只输出验证动作 + 复盘入口

## 检查点（4个）

| CP | 时机 | 确认内容 | 标记 |
|----|------|----------|------|
| 🔴 CP1 | 类型识别后 | 类型判断和模块选择是否正确？ | STOP |
| 🔴 CP2 | 路径选择后 | 分析路径和优先级是否合适？ | STOP |
| 🔴 CP3 | 盲点输出后 | 这些盲点是否击中你的困惑？ | STOP |
| 🔴 CP4 | 验证动作后 | 下一步行动是否可执行？ | STOP |

## Thinking OS 七层速查

| 层 | 名称 | 目标 | 关键词 |
|----|------|------|--------|
| 1 | 哲学 | 定义问题 | 表象vs深层, 隐藏前提 |
| 2 | 系统 | 识别结构 | 反馈回路, 杠杆点 |
| 3 | 概率 | 处理不确定 | 置信度, 黑天鹅 |
| 4 | 经济 | 评估代价 | ROI, 机会成本, 隐性成本 |
| 5 | 政治 | 看清权力 | 利益方, 否决权, 叙事 |
| 6 | 军事 | 形成行动 | 第一胜利, 资源集中 |
| 奇正* | 非线性破局（可选激活） | 双约束死结, 路径绕行, 第三条路 |
| 7 | 元认知 | 校准自己 | 情绪驱动, 认知偏差, 框架锁定 |

## Evolution OS 演化链

```
事件本质 → 技术 → 产业 → 组织 → 社会 → 权力 → 人性 → 新秩序 → 反向推演 → 认知资产 → 输出
```

## 奇正思维五步速查

| 步骤 | 一句话 |
|------|--------|
| 约束消解 | 拆"字面要求"和"实际目的"，缝隙就是空间 |
| 资源翻转 | 把约束本身变成你的资本 |
| 路径绕行 | 重定义问题，让二选一消失 |
| 跨域借力 | 别的行业早解决过类似问题 |
| 矛盾统一 | 找C，C同时是A和B |

激活信号：双约束死结 / 选项枯竭 / 正面硬刚 / AI拒绝区 / 线性循环

## 输出格式（6块）

1. 输入类型识别
2. 用户真正应该思考的问题
3. 可能忽略的结构/权力/风险
4. 需要调用的认知资产
5. 期演化视角（如适用）
6. 下一步验证动作
